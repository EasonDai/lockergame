# 爷爷奶奶的旧屋

一个温馨向的 3D 网页解谜小游戏：回到爷爷奶奶的旧屋，在老家具里找出他们留下的礼物与心意。卡通描边风格，单个 HTML 文件，打开浏览器就能玩，电脑和手机都支持。

- **第一章 · 奶奶的柜子**：奶奶出门旅行，在绿色木柜里藏了留给你的礼物。
- **第二章 · 爷爷的书桌**：通关第一章后解锁。在爷爷的旧书桌前，借着昼夜和灯光，拼出一段藏了几十年的心意。

---

## 快速开始

游戏通过 importmap 从 unpkg CDN 加载 Three.js，**首次打开需要联网**。建议用本地服务器打开（直接双击 `index.html` 在部分浏览器里也能运行）：

```bash
cd "可交互 柜子网页 OPS 5.5版本"
python3 -m http.server 8765
```

然后访问 <http://localhost:8765>。

在线试玩：<https://easondai.github.io/lockergame/>

手机测试：手机和电脑连同一个 Wi-Fi，用上面的命令启动（不要加 `--bind 127.0.0.1`），手机浏览器访问 `http://电脑局域网IP:8765`。

## 操作方式

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 旋转视角 | 按住鼠标拖动 | 单指拖动 |

第一次打开会自动播放 5 步新手指引（旋转、缩放、点击、使用道具、组合道具），可以点「跳过」。

## 游戏内容

### 第一章 · 奶奶的柜子（9 个进度点）

🗝️ 拿到钥匙 → 🚪 打开柜门 → 💡 修好台灯 → 🔢 打开抽屉 → 🎣 钓出纸条 → 👀 看懂涂鸦 → 📻 收听电台 → 🐟 喂饱团子 → 🎵 打开八音盒

特色机制：闹钟拨时间、书脊密码、道具组合（磁铁 + 毛线 = 钓竿）、**换角度才能看懂的错视涂鸦**、收音机调频、木琴弹奏。

### 第二章 · 爷爷的书桌（8 个进度点）

📷 打开中间抽屉 → 🏮 盖对印章 → 🌙 看见夜光字 → 🌍 找到杭州 → 🗝️ 打开右上抽屉 → 👤 拼出影子 → 📔 读完日记 → 🌳 窗外的老槐树

特色机制：

- **昼夜切换**：点铜日晷让屋里天黑。有些线索只在夜里出现（夜光字、窗台上的碎片、墙上的影子虚线）。
- **民国纪年换算**：线索分散在结婚照背面、茶杯底、挂历上，还有干扰项。
- **印章顺序**：从情书里的诗读出五枚印章的顺序。
- **地球仪经纬度**：用放大镜看地球仪，拨到正确的经纬度。
- **影子谜题（核心）**：先把旧照片立在灯座旁当参照（不放照片就看不到目标轮廓，也无法过关），再把老花镜、茶杯、钢笔摆到台灯前，旋转调整角度，让墙上的影子拼出照片背面画的图案。

### 评分

每章通关时给出 100 分制评分：

| 章节 | 满分条件 |
| --- | --- |
| 第一章 | 10 分钟内完成，不用提示，集齐 3 片拼图 |
| 第二章 | 15 分钟内完成，不用提示，集齐 3 片拼图 |

- 每少找到 1 片拼图碎片扣 5 分（最多扣 15 分）
- 超过满分用时后，每超 1 分钟（不足 1 分钟按 1 分钟算）扣 2 分，最多扣 50 分
- 评语：100 完美通关 · 90+ 太厉害了 · 75+ 很棒 · 60+ 不错哦 · 其他 顺利通关

### 结局分享卡

每个结局（包括隐藏结局）的弹窗里都有「📸 分享卡」按钮，会生成一张竖版卡片（720×1080，2 倍清晰度），上面有结局照片（集齐碎片的程度会如实显示）、一句台词、分数和评语、用时 / 提示 / 碎片，以及日期。可以「💾 保存图片」，支持的浏览器（多数手机）还能直接「📤 分享」；手机上也可以长按图片保存。卡片由 Canvas 现场绘制，不需要联网。

### 隐藏结局

第一章的抽屉密码锁输入 **2020**，可以直接触发隐藏结局「奶奶的万能钥匙」，跳过剩下的谜题，然后可以进入第二章。隐藏结局不参与评分。

### 隐藏收集

每章各藏有 3 片照片碎片 🧩，结局照片上会按找到的数量补上缺口：

- 第一章集齐：全家福完整，结局多一段奶奶的 P.S.。
- 第二章集齐：拼出「老槐树下 · 我们三个」的合影，窗外的树下还会多出两把椅子和一颗小心。

## 存档

- 进度自动保存在浏览器 `localStorage`，键名 `cabinet-puzzle-v2`；背景音乐开关单独存在 `cabinet-bgm`。
- 换浏览器、开无痕模式或清除网站数据都会丢失进度。
- 想彻底清档：游戏内「↻ 重来 → 整个游戏重新开始」，或在浏览器控制台执行 `localStorage.clear()`。

## 技术栈

- **Three.js r160**（ES Module + importmap，CDN 加载），OrbitControls 控制镜头
- 卡通着色 + 背面外扩描边，悬停时描边高亮
- 画面里的文字、影子、窗外景色用 Canvas 动态绘制成贴图
- 音效和背景音乐用 Web Audio API 实时合成，**没有任何外部素材文件**
- 无构建步骤、无依赖安装

### 代码结构（`index.html` 内的 `<script type="module">`）

| 模块 | 关键名字 |
| --- | --- |
| 基础工具 | `mat()` `M()` `place()` `tween()` `register()` `canvasTex()` |
| 存档状态 | `S` `save()` `setFlag()` `CH2_DEFAULT` |
| 道具 / 背包 | `ITEMS` `COMBOS` `gainItem()` `select()` `updateInv()` |
| 进度 / 提示 | `STEPS` `STEPS2` `HINTS` `HINTS2` `stage()` `stage2()` |
| 第一章场景 | `cab` 组：闹钟、柜门、台灯、抽屉、猫、收音机、八音盒…… |
| 第二章场景 | `desk` 组：日晷、台灯、地球仪、印章盒、影子谜题、窗户…… |
| 结局 / 分享卡 | `showEnding()` `showEnding2()` `showSecretEnding()` `openShareCard()` `drawShareCard()` |
| 章节切换 | `enterCh2()` `setChapter()` `applyState()` `applyState2()` `resetCh2()` |
| 交互 | `pick()` `pickNear()`（触屏扩大判定范围）`activate()` |
| 新手指引 | `startTutorial()` |

### 新增一个可交互物体的套路

```js
const thing = new THREE.Group();
place(desk, thing, x, y, z);                 // 挂到对应章节的组里
place(thing, M(rbox(0.3, 0.2, 0.3), '#c97'), 0, 0.1, 0);
register(thing, {
  name: '物体名',
  tip: () => '鼠标悬停提示',
  desc: '没有特殊逻辑时点击显示的描述',
  onClick() { /* 返回 true 表示已处理 */ },
  onUse(item) { /* 对它使用道具；返回 true 表示用上了 */ },
});
```

注意：

- 子物体要先于父物体 `register`，否则描边高亮会被父物体占走。
- 第二章的东西一律挂在 `desk` 下面，不要直接加到 `world` / `scene`，否则会在第一章露出来。
- 新增状态字段：第二章的加进 `CH2_DEFAULT`，并在 `applyState2()` 里恢复对应的画面。
